# FitSphere

Coach-led fitness app: clients log food, body metrics and workouts against coach-set targets.

## Status
Pre-development. Documentation only — no application code yet. Approved stack (ADR-0001 to
ADR-0003): React Native with Expo; a TypeScript Node.js API; Supabase PostgreSQL and file storage
in Mumbai. Details and what is still open: [`CLAUDE.md`](CLAUDE.md#current-phase).
